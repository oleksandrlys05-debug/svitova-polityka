# Світова політика

Стратегічна гра для компанії друзів: держави на мапі, дипломатія, економіка, війни.

**Поточна версія: 21.2.0**

## Завантажити

| Для чого | Файл |
|---|---|
| Windows (програма, грати й створювати світ) | [Svitova-Polityka-Windows.zip](https://github.com/oleksandrlys05-debug/svitova-polityka/releases/latest/download/Svitova-Polityka-Windows.zip) |
| Телефон Android (Termux) чи сервер | [arma-politics.zip](https://github.com/oleksandrlys05-debug/svitova-polityka/raw/main/release/arma-politics.zip) |

**Windows:** розпакуйте архів (можна поверх старої версії — збереження не зникнуть) і запустіть `SvitovaPolityka.exe`.
Далі програма оновлюється сама: під час запуску вона перевіряє, чи вийшла нова версія, і пропонує «Оновити зараз».
Зі старою версією зайти в гру не можна.

**Телефон:** `bash ~/proj/start-android.sh` сам перевіряє й встановлює оновлення перед запуском
(або вручну: `bash ~/proj/update-android.sh`).

## Що нового у 21.2.0
- Лобі з кількома іграми: на сервері тепер 3 гри одночасно, адмін може створювати нові
- Нова гра 5 хвилин чекає голосування гравців за мапу
- У кожній грі свій акаунт; грати можна максимум у 2 іграх одночасно
- Кнопка «◂ Ігри» в грі повертає до вибору гри
